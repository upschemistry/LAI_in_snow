The file filelist_all.txt contains file locations and volumes for filters in this folder. The list has line breaks in it to separate out different categories, which are separated into subcategories, as described below:


The file filelist_all_2020.txt contains file locations and volumes for 2020, and the corresponding LAHM_Analysis results (ugbasic, naperg, and t0) for each readable file, run in late July 2026.

UPS2020-1 to 29
These are LAHM temperature traces for filters taken from samples at sites 1-4 on Mt. Rainier (see UPS metadata/Filtering_Field_Data (2020).xlsx for site lat/long, snow levels, dates. Similar information -- but including site # and level # -- is available in UPS metadata/LAHM_21.xlsx.

UPS2020-D1 to D6
Dirt (I think, because they all have the same volume). Useful to get a range of values of t0 and AAE, but not as snow loadings. 


The file filelist_all_2021.txt contains file locations and volumes for 2021, and also contains LAHM_Analysis results (ugbasic, naperg, and t0) for each readable file. 

UPS2021-1 to 5
Todd Field on the UPS campus. Site # and level # are available in UPS metadata/LAHM_21.xlsx. There is also some metadata about these samples in UPS metadata/Data 2021.

UPS2021-R1 to R37
Site # and level # are available in UPS metadata/LAHM_21.xlsx. The site numbers vary, but the metadata in UPS metadata/Data 2021 say that the location is "Above Paradise to the northwest, same location as site 1."

UPS2021-S1, S2, and S4 (S3 is not readable)
Snoqualmie. Site # and level # are available in UPS metadata/LAHM_21.xlsx.
